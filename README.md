# Crescendo

A single-page, interactive tension-and-release experience. Pure HTML, CSS and JavaScript with no build step.

Modes: Tease (drag), Press (hold), Rhythm (tap a steady beat). Keys 1, 2 and 3 switch modes; Space holds in Press mode.

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Push `index.html` to the root of a repository.
2. Go to Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch, pick `main` and `/ (root)`, then Save.
4. Your site goes live at `https://<username>.github.io/<repo>/` within a minute or two.
